One Emoji, One Smile — an entry for the [make.fun bounty](https://make.fun/c/u-0xkianno-one-emoji-one-smile-5470751f).

The program (`main.ts`, Node 22) writes exactly one emoji to `/output/entry.txt` and nothing else: no words, no caption, no explanation.

The chosen emoji is 🤗, the hugging face. A stranger glancing at a phone screen reads open arms at once — a warm, friendly welcome that needs no context and reads the same at any age and in any language. It is a deliberate pick rather than the first smiley that comes to mind, and it stays on the friendly side of the line: a hug offered, not intimacy or flirtation from someone unknown.
